# 启动器外壳选型决策记录（2026-10-26）

- **生产启动器壳：`src-egui`（egui/eframe 0.35 原生 UI）**
- `src-tauri`（Tauri 2 + Vue 3）：已于 **删除**（2026-10-26 起）。其 Vue 前端（`src/`、`public/`、`index.html`、`preview.html`、`vite.config.js`、`dist/`）与 pnpm 依赖一并移除；仅保留 `src-core` + `src-egui` 两条线。
- `src-zsui`（zsui 原生 UI）：已于 **删除**（2026-10-26 起）。

## 依据

1. **产品定位 = 固定启动器/更新器**：以显示为主（5 套模板 A~E、深色渐变 440×420、更新日志、进度条/环形进度、日志区），跑完更新后自动退出（实测约 51s 后退出码 0）。UI 上线后基本冻结，手绘成本属于一次性沉没成本。
2. **业务层已与外壳解耦**：下载 / 校验 / 安装 / 启动 / 重试全部收敛在共享 crate `src-core`（`phase.rs` / `flow.rs`）；Tauri 与 egui 都只是渲染同一套 `phase` / `flow`，切换外壳零逻辑重写。
3. **实测对比（Win11 x64，release，同一 mock 流程）**：
   - 内存峰值：Tauri 进程树 ~354–362 MB；egui 单进程 ~162–177 MB（约省一半）。
   - 启动到可见：Tauri ~835ms（splash 757ms）；egui/glow ~558ms、egui/wgpu ~776ms。
   - 产物：egui 单文件 9.7–15.4MB，无 WebView2 依赖；Tauri exe 11.1MB + 系统 WebView2。
   - CPU/GPU：更新期 Tauri CPU 43.3%；egui 10.6–11.2%，GPU 均近 0。
4. **egui 已验证全功能**：1920×1080 居中偏差 (0,0)；更新完成自动关窗；5 套模板含更新日志均像素级验证通过；`src-core` 单测 135 passed。

## 代价与限制（沿用 egui 需注意）

- UI 每改一次需改 Rust 并重编，无现成组件 / i18n 框架；CJK 需嵌字体（已解决）。
- IME / 无障碍弱于 WebView，但启动器无文本输入，影响可忽略。
- 未来若启动器长成带设置 / 账号 / 多页面的功能型客户端，需重新评估（彼时 Tauri + Vue 复用 `frontend-thin-i18n` 更优）。
