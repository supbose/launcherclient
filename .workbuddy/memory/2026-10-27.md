### egui 0.35 API 踩坑（重要，后续别再踩）
- `Frame` 没有 `none()` → 用 `Frame::default()`
- `Frame`/`Button` 的圆角是 `corner_radius(...)`，不是 `rounding(...)`
- `Button::min_size` 要 `Vec2`（用 `egui::vec2(a,b)`），不能传 `[f32;2]`
- `Margin::symmetric` 参数是 **i8**（整数），不是 f32
- `Button` 无 `expand_width`；想铺满用 `min_size(egui::vec2(ui.available_width(), h))`
- 窗口居中：`ViewportBuilder` 没有 `centered()`；靠运行时
  `ViewportCommand::center_on_screen(ctx)` + `ctx.send_viewport_cmd`

## 升级 egui/eframe 0.35 → 0.37（commit `e54a36e`）

### 唯一的破坏性变更

### 重要结论：渲染后端没变（别再被旧注释误导）
`src-egui/Cargo.toml` 原注释写「glow 渲染后端」是**错的**——
查 eframe 0.35 与 0.37 的 `[features] default`，两者都是 **wgpu**。
所以 0.35→0.37 **不涉及渲染后端切换**，生产启动器在客户机的 GPU 兼容性无回归。
已顺手把该注释改为「默认 feature 即走 wgpu 渲染后端，与 0.35 一致」。
0.37 新增的 default feature：system_fonts（egui_system_font_provider）、clipboard、links。
system_fonts 让 egui 可自动取系统字体，但项目里的手动 install_fonts 仍保留作为中文显式保证。
